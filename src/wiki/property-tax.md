## Overview

Property tax is the primary funding source for most [[municipality-of-anchorage]] service areas, including Girdwood's [[girdwood-service-area]] (fund `106000`, see [[muni-funds]]). The [[municipality-of-anchorage]] Property Appraisal Division assesses each property's value [at what frequency??]; the tax owed is that assessed value (less any exemptions) times the mill rate set for the property's service areas.

This page is a hub — see the linked pages below for detail.
